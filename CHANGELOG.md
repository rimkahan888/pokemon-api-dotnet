## [0.1.0] - 2026-10-24

Initial explorer available on `main`.

### Added

- ASP.NET Core API that proxies PokéAPI with retries, timeouts, and memory caching
- Paginated Pokémon list, catalog search, and detail endpoint
- Vue app with loading, empty, and error states, favorites, and a six-Pokémon team
- Team type coverage and shared-weakness analysis
- xUnit and Vitest suites, plus a GitHub Actions build
